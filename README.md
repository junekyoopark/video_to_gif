# video_to_gif
Video to GIF GUI tool using FFmpeg

# Usage
1. Clone this repo
   ```
   git clone https://github.com/junekyoopark/video_to_gif
   ```
2. Install dependencies

   MacOS

   ```
   # install brew, not required if already installed
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
   ```
   # then install FFmpeg
   brew install ffmpeg
   ```

   Ubuntu/Debian
   ```
   sudo apt update
   sudo apt install ffmpeg
   ```

   Windows
   ```
   # install chocolatey
   https://chocolatey.org/install
   ```
   ```
   # then install FFmpeg
   choco install ffmpeg
   ```

3. Run this software
   ```
   python video_to_gif.py
   ```
